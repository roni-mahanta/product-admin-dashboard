# Product Admin Dashboard

A responsive product management dashboard built with **Next.js, React, Tailwind CSS, Axios, and DummyJSON API**.

The application provides authentication, product listing, search, filtering, sorting, pagination, product details, and CRUD operations through a clean and responsive admin interface.

---

## 🚀 Live Features

- 🔐 User authentication
- 🛡️ Protected dashboard
- 🚪 Logout functionality
- 📦 Product management
- 🔎 Product search with debounce
- 🏷️ Category filtering
- ↕️ Product sorting
- 📄 Pagination
- 📱 Responsive desktop and mobile layouts
- 👁️ Product details page
- ➕ Add products
- ✏️ Edit products
- 🗑️ Delete products
- ⚠️ Loading, error, and empty states
- 🔄 Retry functionality
- 🔗 URL-based search, filters, sorting, and pagination
- 🚫 Invalid product/page handling
- 📡 Centralized Axios API configuration
- 🔑 Automatic authentication token handling
